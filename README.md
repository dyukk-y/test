# 🚔 DPS Guardian 3.0

Telegram-бот для водителей Маслянинского района: где стоят ДПС, камеры и радары, где ДТП и опасные участки.
Водители сообщают сами, бот понимает обычный «шофёрский» язык, проверяет информацию голосованием,
предупреждает о нарядах **впереди по курсу** и строит прогноз по статистике.

## Возможности

### Для водителей
| | |
|---|---|
| ✍️ **Отчёт обычным текстом** | «гайцы с феном на выезде из маслянки в сторону новосиба» → радар, Маслянино, выезд, направление Новосибирск. Понимает сленг (гайцы, мусора, фен, тренога, полосатые), сокращения (ул, пов, азс, тц, км, щас), опечатки, падежи («в Большом Изыраке»), неверную раскладку (`lgc` → дпс), латиницу-двойники (`ДПC`), госномера (в т.ч. полицейские `А1234 54`). Перед публикацией показывает, *что понял*, и даёт уточнить. |
| 📍 **Отчёт в 2 касания** | Отправить точку → «🚔 Тут ДПС». Метка с точностью GPS. |
| 🛰 **Режим «в дороге»** | Транслируете геопозицию — бот следит за курсом и предупреждает только о том, что **впереди**, а не позади. |
| 🔔 **Уведомления** | По подписке на сёла, по радиусу вокруг точки, выбор типов событий, тихие часы. |
| 🗳 **Проверка сообществом** | «✅ Стоят» продлевает событие, «👋 Уехали» закрывает, «🚫 Фейк» удаляет. Повторный отчёт рядом не дублирует, а подтверждает. «Чисто у моста» — отбой текстом. |
| ⭐ **Репутация** | Подтверждённые отчёты повышают репутацию, фейки понижают. Доверенные публикуют без модерации, злостные фейкеры блокируются автоматически. |
| 🔮 **Прогноз** | Где наряды обычно стоят в этот день недели и час (по истории за 90 дней) + график активности по часам. |
| 🗺 **Карты** | Интерактивная HTML (слои по типам, круги точности, тепловая карта «горячих точек») и картинка PNG. Кнопки «Яндекс / Google / точка в Telegram». |
| ❓ **Вопросы** | «Есть ДПС в Маслянино?» → бот отвечает по текущим данным. |

### Сбор данных
* **Водители** — текст, фото с подписью, геопозиция.
* **Чаты водителей** — добавьте бота в местный чат: он сам распознаёт сообщения о ДПС и ставит 👀.
  Нужно выключить privacy mode (@BotFather → Bot Settings → Group Privacy → Turn off) или сделать бота админом.
* **Telegram-каналы** — через аккаунты-парсеры (Telethon) в реальном времени + догрузка пропущенного.
  Вход в аккаунт прямо в боте (телефон → код → пароль 2FA).

### Точная геолокация
Порядок определения места (от точного к грубому):
1. **GPS** из Telegram (с учётом точности устройства);
2. **ориентиры администратора** — `/setplace ТЦ Радуга; радуга` + точка на карте;
3. **самообучение**: когда кто-то пишет «ДПС у моста в Бажинске» *и* присылает GPS, бот запоминает, где этот мост.
   Потом текстовые отчёты «у моста в Бажинске» ставятся в выученную точку (медиана, отсев выбросов);
4. **OpenStreetMap (Nominatim)** — улицы и заведения внутри района, с кэшем и лимитом 1 запрос/сек;
5. **центр села** — честно помечается как «примерно» с радиусом точности.

Координаты сёл в справочнике при старте автоматически уточняются по OpenStreetMap, а админ может поправить
любое село: `/setvillage Бажинск` + точка.

### Для администратора (`/admin`)
Модерация, статистика и топ помощников, источники и аккаунты-парсеры, ориентиры, баны, админы
(добавлять/удалять может только владелец), настройки (режим модерации, время жизни событий, лимиты, пороги),
рассылка любых сообщений с прогрессом, бэкап по кнопке и ежедневно в 04:00 (хранятся последние 14).

Команды: `/user ID`, `/ban ID причина`, `/unban ID`, `/trust ID`, `/untrust ID`, `/givepremium ID дней`,
`/refund ID charge_id`, `/setplace`, `/setvillage`, `/delplace`.

### Премиум
Оплата **Telegram Stars** (встроенные платежи Telegram, без ручных переводов). Даёт режим «в дороге»,
радиус до 10 км и безлимит подписок на сёла. Можно отключить: `PREMIUM_ENABLED=0` — тогда всё бесплатно.

## Запуск

```bash
git clone https://github.com/dyukk-y/test.git dps-bot && cd dps-bot
cp .env.example .env    # впишите BOT_TOKEN и OWNER_IDS
```

**Docker (рекомендуется):**
```bash
docker compose up -d --build
```

**Без Docker** (Python 3.10+):
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m dps_bot
```

Все данные (база, логи, бэкапы, сессии парсеров) — в папке `data/`.

### Сбор из каналов (необязательно)
1. Получите `api_id` и `api_hash` на https://my.telegram.org → API development tools, впишите в `.env`.
2. `/admin` → 👥 Аккаунты-парсеры → добавить (лучше отдельный аккаунт, не основной).
   Код из Telegram вводите **с пробелами** (`1 2 3 4 5`), иначе Telegram его аннулирует.
3. `/admin` → 📡 Источники → добавить `@канал` или ссылку-приглашение.

## Разработка

```bash
pip install -r requirements-dev.txt
python -m pytest -q
```
Тесты гоняют реальные апдейты Telegram через диспетчер с фейковым API: отчёты, слияние, голосование,
уведомления, модерацию, группы, баны, карты, оплату.

```
dps_bot/
  __main__.py      запуск, сборка диспетчера
  config.py        настройки из .env
  db.py            SQLite (aiosqlite, WAL), схема
  nlp.py           понимание текста: тип, место, направление, номер, отбой, вопрос
  gazetteer.py     сёла района и направления
  geo.py           геолокация: ориентиры, самообучение, OSM, сёла
  events.py        события: слияние, голосование, истечение, репутация
  notify.py        уведомления: сёла, радиус, «впереди по курсу»
  forecast.py      прогноз по истории
  maps.py          HTML- и PNG-карты
  parser.py        каналы через Telethon
  handlers/        user · settings (+Stars) · group · admin
  tasks.py         фоновые задачи
```

## Что изменилось по сравнению со старой версией
* Токен больше не в коде — только `.env`. **Старый токен нужно отозвать в @BotFather (`/revoke`).**
* Убран фиктивный «авто-вывод» (он ничего не переводил, а лишь помечал случайные суммы выполненными)
  и ручная оплата на кошелёк — вместо них честные Telegram Stars с возвратами.
* Исправлены: пагинация, сравнение времени (UTC в едином формате), бесконечные «фейки» одним человеком,
  «удаление админа», которое добавляло админа, падения на `_` и `*` в тексте (теперь HTML с экранированием),
  блокировка бота геокодером и отрисовкой карт, бесконечный рост папки `maps/`, неустановленные места в
  центре райцентра, перезапись премиума при продлении.
